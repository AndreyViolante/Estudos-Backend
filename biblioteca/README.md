# Biblioteca - Django

Sistema de gerenciamento de acervo de biblioteca com filtros avançados.

## Funcionalidades

- ✅ Listar todos os livros
- ✅ Cadastrar novo livro
- ✅ Filtrar por nome
- ✅ Filtrar por tipo (Digital/Físico)
- ✅ Filtrar por categoria (000-900)

## Como usar

1. Ativar ambiente: `venv\Scripts\activate`
2. Rodar servidor: `python manage.py runserver`
3. Acessar: http://localhost:8000/livros/
4. Admin: http://localhost:8000/admin (admin / 123456)

## Tecnologias

- Django 6.1.1
- Python 3.x
- SQLite
